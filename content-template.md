# Шаблон для заповнення контенту сайту

Як цим користуватись: заповнюєш один блок нижче (одну сторінку) → копіюєш заповнений блок у Claude Code разом із коротким промтом-обгорткою (внизу файлу, розділ "Як вписувати в промт") → Claude Code міняє лише текст на вказаній сторінці, не чіпаючи HTML-структуру, CSS, SEO-теги й JSON-LD. Так простіше: одна сторінка = один прогін = легко звірити результат, замість "заповни весь сайт одним промтом", де важко проконтролювати якість.

Рекомендований порядок заповнення: Головна → Про мене → 8 сторінок послуг → Ціни → Онлайн-консультації → Для українців за кордоном → Контакти → Відгуки → Блог (статті можна додавати поступово, будь-коли) → Політика конфіденційності (можна лишити типовий текст, який уже згенерував Claude Code).

---

## Як вписувати в промт

Формула, яка працює стабільно (не проси "онови весь сайт" за раз):

```
Онови сторінку [шлях до файлу, напр. posluhy/tryvoga-panichni-ataky/index.html]
реальним контентом нижче. Заміни лорем іпсум у відповідних блоках,
збережи HTML-теги, класи, структуру h1/h2/h3, FAQ-розмітку і JSON-LD —
онови в JSON-LD тільки текстові поля (питання/відповіді FAQ), не структуру.
Онови також <title> і meta description на вказані нижче.

[тут вставляєш заповнений блок зі шаблону нижче]
```

Якщо після заміни щось виглядає не так (задовгий/закороткий текст ламає верстку) — окремим промтом: "текст у блоці [назва] тепер не влазить у картку, поправ або текст, або CSS-відступи, не змінюючи дизайн".
